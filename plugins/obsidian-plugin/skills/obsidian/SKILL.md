OB文档规则

# 文档属性
文档需要有文档属性
- tags : 罗列几个文档相关的tags
- created： 时间
- author ： 用户名
- project : 如果有工程信息，则罗列工程信息
- description : 文档简述


# 反向连接
添加必要的反向连接，来连接文档

# 步骤
1. 与用户确认vault
2. 与用户确认文件位置和目录
3. 与用户确认文档属性

在确认了以上信息后，开始创建文档
