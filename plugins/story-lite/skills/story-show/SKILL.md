# Story Show

把用户需求落地为实际 `.html` 文件。默认输出单文件、零构建、零外部依赖，可直接在浏览器打开。

## 工作流

### 1. 提取需求

确认以下信息：

- 页面目标：说明、演示、计算器、参数测试或数据可视化。
- 输入参数：名称、单位、默认值、范围和步长。
- 计算规则：公式、严格/非严格边界、倍率、钳制和状态分支。
- 输出内容：判定、指标、图形、提示和异常状态。
- 输出路径：用户指定优先；未指定时在当前工作目录生成语义明确的 `.html` 文件。

仅当缺失信息会改变核心语义时提问。其余事项采用最小可行默认值，并在页面中写明假设。

### 2. 核实事实

需求来自现有代码时，先读取实际实现：

- 保留单位、坐标系和角度定义。
- 保留 `>` / `<` / `>=` / `<=` 的真实边界。
- 保留倍率叠乘、Clamp、状态差异和默认值。
- 区分配置原值、运行时有效值和调试绘制值。

页面结论必须由同一套计算状态驱动，禁止手写一份结果、绘图再使用另一套公式。

### 3. 选择页面形式

- 只需阅读：生成静态说明页。
- 参数会变化：生成交互式测试工具。
- 存在空间关系、流程或范围：使用内联 SVG。
- 用户指定现有 HTML：先读取并原地更新。

用户要求“直接修改”时，只修改目标 HTML，不创建附加需求文档或工程配置。

### 4. 实现

必须：

- 创建或更新真实 `.html` 文件，不能只在对话中输出代码块。
- 内联 HTML、CSS、JavaScript 和 SVG。
- 使用响应式布局及高对比度颜色。
- 为输入项标明名称与单位，提供合理的 `min`、`max`、`step` 和默认值。
- 参数变化时实时刷新结果、公式和图形。
- 提供“恢复默认值”。
- 用 `textContent` 写入动态文本。
- 对空值、零距离、零半径和极端角度提供稳定结果。
- 将计算、状态更新和绘图拆成职责明确的函数。

默认禁止：

- `fetch()`、CDN、外部字体和第三方脚本。
- `eval()`、`new Function()` 和字符串拼接执行代码。
- npm、构建流程、开发服务器及多文件前端工程。
- 为未提出的场景增加框架、持久化或复杂配置系统。

## 交互测试工具约定

采用以下数据流：

1. 从控件读取并约束参数。
2. 在单一计算函数中生成完整状态。
3. 由状态更新数值、判定说明和样式。
4. 由同一状态重绘所有视图。

空间图形应：

- 先在世界坐标中计算，再分别投影到视图。
- 根据当前几何范围自动缩放，保持纵横比。
- 清楚区分对象、目标、有效范围、边界和超出部分。
- 同时展示关键尺寸与最终判定。

涉及参数化几何与 SVG 投影时，按需读取 [REFERENCE.md](REFERENCE.md)。

## 视觉标准

- 主结果最醒目，参数区和辅助指标次之。
- 成功、失败和警告颜色含义保持一致。
- 避免渐变、阴影、装饰性边框和无意义卡片堆叠。
- 桌面端并排展示视图，窄屏自动改为单列。
- SVG 添加 `<title>`、`<desc>`，动态结果使用 `aria-live="polite"`。

## 验证

完成后静态检查：

- HTML 标签闭合，`id` 唯一且脚本引用均存在。
- 无未请求的外部资源和网络调用。
- 默认参数计算结果与需求一致。
- 至少核对：正常值、边界值、零值、倍率变化、角度内外。
- 图形与数值使用同一状态，坐标比例和方向一致。
- IDE 诊断无新增错误。

默认不启动服务器、不引入依赖。用户明确要求运行验证时再执行。

## 交付

返回：

- 可点击的 HTML 文件路径。
- 可修改的参数概览。
- 默认场景的关键判定。
- 已完成的验证类型。
