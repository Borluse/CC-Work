# Review 报告模板

按高→中→低分组（空组省略）。`R1` 起全报告连续编号。涉及文件可并列，无则写「无」。Quick 用任务短语作为关联需求。

```markdown
# <需求N_标题或Quick任务>_<方案/设计或代码>review
- 日期：YYYY-MM-DD
- 关联需求：<需求N_标题或Quick任务>
## 1. 问题清单

### 🔴 高

- **R1** `path/to/file`
  - 问题：…
  - 原因：…
  - 影响：…
  - 建议：…

### 🟡 中
（同结构；编号续排）

### 🟢 低
（同结构；编号续排）

## 2. 修复记录
```
