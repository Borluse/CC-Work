# 正式需求模板

## 原始需求

```markdown
# 原始需求：<slug 描述>
- <YYYY-MM-DD HH:mm>：初始创建
（后续变更记录继续追加在标题下）
## 1. 需求背景
## 2. 需求描述
## 3. 验收标准
```

## 总览

需求点章节从 `## 5` 起连续编号；变更记录使用最后一个需求点后的编号。

```markdown
# 总览：<slug 描述>
## 1. 整体目标与技术约束
## 2. 现有系统盘点
| 系统/模块 | 位置 | 关系 |
|-----------|------|------|
| … | … | 复用/扩展/继承 |
## 3. 需求点清单
| 编号 | 名称 | 目标 | 功能范围 | 方案思路 | 依赖 |
|------|------|------|----------|----------|------|
| 1 | … | … | … | … | - |
## 4. 实施依赖
（使用 mermaid flowchart，并列出实施顺序）
## 5. 需求点 N：<标题>
- 状态：待设计
- 关键决策：…
- 设计文档：-
- Review：-
## 6. 变更记录
- <YYYY-MM-DD HH:mm>：说明
```

## 需求点

```markdown
# 需求N：<标题>
- 状态：<枚举值>（仅既有无总览单点需求）
- 关键决策：…（仅既有无总览单点需求）
- Review：<链接>（仅既有无总览单点需求且已有报告时）
## 1. 需求简介
一句话。
## 2. 功能说明
策划目标 + 技术行为。
## 3. 设计细节
设计要点（可配 mermaid/伪代码）。
## 4. 变更记录
- <YYYY-MM-DD HH:mm>：初始创建/修改
```
