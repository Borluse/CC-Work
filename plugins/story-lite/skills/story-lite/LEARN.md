# 知识沉淀

前置：已完成主技能定位，并已读取主技能的约定、状态规则与模板门禁。

入口：首次正式需求到达 `已完成` 且存在可跨需求复用知识，或 Bug 到达 `已验证` 且存在可跨需求复用知识，或用户明确要求「沉淀」「提炼方法论」「写入 library」时进入本模式。

出口：用户确认沉淀后委托 `../story-lite-learn/SKILL.md`；用户未确认或明确跳过时结束，不重复提醒。

## 1. 提示与确认

1. 首次正式需求到达 `已完成`，若存在可跨需求复用知识：仅提示一次并等待用户决定。
2. Bug 到达 `已验证`，若存在可跨需求复用知识：仅提示一次并等待用户决定。
3. 用户明确说「沉淀」「提炼方法论」或「写入 library」时直接进入本模式。
4. 提示本身不是进入 `story-lite-learn` 的许可。用户未确认或明确跳过：结束跟进，不在下一收尾点重复提醒。
5. 若无可沉淀内容：只报告并结束，不读取配套 skill。

## 2. 委托执行

1. 用户确认沉淀后，读取并进入 `../story-lite-learn/SKILL.md`。
2. `story-lite-learn` 负责候选知识收集、核实、与现有 library 对比、预览确认和实际写入。
3. 本模式不重复知识提炼规则，不直接写入 library；无可沉淀内容时只报告并结束。
