- **前置**：加载 `${CLAUDE_SKILL_DIR}/../common/basic.md`（同会话已读则跳过）。

从当前对话上下文或 `.agent/story/` 下的设计文档中，提炼可复用模式写入 `.agent/library/`。

## 规则

- 中文撰写
- **线索导向**：只写职责描述 + 入口函数名/类名/文件路径，不罗列具体 API 签名和参数属性。代码会变更，library 只提供搜索起点，具体接口交给 AI 实时探索源码
  - ✅ `状态查询（存活/战斗/仇恨）→ IsAlive`
  - ❌ `IsAlive() / IsCombat() / GetMainHateTarget() - 主仇恨目标`
- 只提炼**可跨需求复用**的模式，需求特有逻辑不提取
- 默认从当前对话上下文提炼；用户明确指定 story 时，按 `basic.md` 的「Slug 检索流程」定位目标 slug 目录后再扫描其下文档。

## 流程

### 1. 读取 library 现状

若本次会话尚未读过 `.agent/library/overall.md` 及相关子文档，则读取一次了解已有内容；已读过则跳过。

### 2. 提炼并展示

从上下文中提取可复用模式，与 library 对比后分类：
- **新增**：library 中没有的
- **增强**：library 中已有但可补充的
- **跳过**：已充分覆盖的

输出精简清单（表格形式）：每条一行，标注目标文档和操作类型。同时给出**写入内容预览**（即实际追加的文本），默认用最精简的表达。

等待用户确认或调整后写入。

### 3. 写入

- 追加到已有文档对应章节，或新建文档并更新 `overall.md` 索引
- 保持与现有文档风格一致
