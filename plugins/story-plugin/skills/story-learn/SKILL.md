### Phase 0: 初始化环境
先调用 `/story-init` 完成工作环境初始化。
- **门禁**：`/story-init` 完成后方可继续，若已执行则跳过。

### Phase 1: 提炼
从当前对话上下文或 `.agent/story/` 下设计文档中，提炼可复用模式写入 `.agent/library/`。

## 规则

- 中文撰写
- **线索导向**：只写职责描述 + 入口函数名/类名/文件路径，不罗列具体 API 签名和参数属性。代码会变更，library 只提供搜索起点
  - ✅ `状态查询（存活/战斗/仇恨）→ IsAlive`
  - ❌ `IsAlive() / IsCombat() / GetMainHateTarget() - 主仇恨目标`
- 只提炼**可跨需求复用**的模式，需求特有逻辑不提取
- 默认从当前对话上下文提炼；用户指定 story 时直接扫描 `<slug_dir>` 下文档。

## 流程

### 1. 读取 library 现状

本次会话未读过 `.agent/library/overall.md` 及相关子文档 → 读取一次；已读则跳过。

### 2. 提炼并展示

从上下文提取可复用模式，与 library 对比分类：
- **新增**：library 中没有
- **增强**：已有但可补充
- **跳过**：已充分覆盖

输出精简清单（表格）：每条一行，标注目标文档和操作类型 + **写入内容预览**。

等待用户确认后写入。

### 3. 写入

- 追加到已有文档对应章节，或新建文档并更新 `overall.md` 索引
- 保持与现有文档风格一致
