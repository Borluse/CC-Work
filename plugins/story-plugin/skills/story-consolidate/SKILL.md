- **必须** 加载 `${CLAUDE_SKILL_DIR}/../common/basic.md`

### 原则对齐
- 目的是为了某个 slug 下需求文档整合在一起。
- 整合后，旧文档应当archive起来

### Phase 1 读取
- 读取slug下所有的需求文档
- 如有总览文档，则读取总览文档

#### Step 2：读取实际代码
- 确保整合后的文档与实际代码一致，区别的地方以实际代码为主

- **以代码为准**：文档描述与代码不一致时，以代码实际实现为准
- **去除历史痕迹**：不保留"修改前/修改后"对比，只描述当前状态
- **删除未实现内容**：代码中不存在的功能不出现在文档中
- **去重合并**：多份文档中重复描述的内容只保留一份
- **保留设计决策**：重要的"为什么这样做"的决策说明要保留
- **标注差异**：发现文档与代码不一致时，记录到差异清单中

合并完成后，输出一份差异报告，列出所有文档描述与代码实际不一致的地方，供用户确认。

### Phase 3 
- 写入或更新总览文档
- 提醒用户打开文件确认
- 展示差异报告摘要

### phase 4 Archive旧文档
- 将旧文档Archive
