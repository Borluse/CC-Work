# Bug 报告文档模板

```markdown
# Bug <N>: <简短标题>

## 复现步骤

1. <步骤1>
2. <步骤2>
3. ...

## 期望行为

<参考关联需求文档的描述，引用具体章节>

## 实际行为

<Bug 发生时的实际表现>

## 关联需求

- `<相对路径/需求文档.md>` - 关联原因说明
- `<相对路径/TDD文档.md>` §X.X - 关联到具体章节

## 根因分析

- **根因**：_分析后填写_
- **证据**：_相关代码、日志或文档依据_
- **影响范围**：_涉及模块与潜在影响_
- **修复路径**：_[小修 / 大修]，附判定理由_

## 修复方案

_用户确认后填写。小修记录拟修改点；大修关联 `/story-design` 产出的设计文档_

## 实际修改

_实施后填写修改文件及关键变更_

## 验证方法

- [ ] <验证步骤1>
- [ ] <验证步骤2>

**验证结果**：_验证后填写_

## 状态

[待确认 / 已确认 / 修复中 / 已修复 / 已验证]

## 变更记录

- **<YYYY-MM-DD HH:mm>**：初始创建
```
