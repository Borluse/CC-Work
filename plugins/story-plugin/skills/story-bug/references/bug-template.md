# Bug 报告文档模板

```markdown
# Bug <N>: <简短标题>

## 复现步骤

1. <步骤1>
2. <步骤2>
3. ...

## 期望行为

<参考关联需求文档的描述，引用具体章节>

## 实际行为

<Bug 发生时的实际表现>

## 关联需求

- `<相对路径/需求文档.md>` - 关联原因说明
- `<相对路径/TDD文档.md>` §X.X - 关联到具体章节

## 根因分析

_修复时填写_

## 修复方案

_修复时填写。小 fix 可简略描述；大 fix 须关联 `/story-design` 产出的设计文档_

## 验证方法

- [ ] <验证步骤1>
- [ ] <验证步骤2>

## 状态

[待确认 / 已确认 / 修复中 / 已修复 / 已验证]

## 变更记录

- **<YYYY-MM-DD HH:mm>**：初始创建
```
