## 概述

分析目标目录下的所有代码文件，归纳每个类/功能的用途，在该目录下生成结构化的 `CODEBUDDY.md`。

## 工作流程

### Phase 1. 读取目录文件列表

用 Bash `fd` 列出目标目录的所有源文件（`.h` / `.cpp` / `.ts` / `.cs` 等），获取完整文件名列表。

### Phase 2. 通过子任务读取并分析代码（**必须**）

**必须**启动一个 `general-purpose` 子任务（Task tool）来完成读取和分析工作。  
**禁止**在主对话中直接读取源文件。

### Phase 3. 生成文件 
根据library目录结构确定更新目标：
根目录位置：`.agent/library/`

- 如果是新的类别，更新**总体文档**：查看`overall.md` 然后找到对应文档
- 如果是通用类别，如c++或者文档规则，更新**通用规则**：`common/` 目录下的相应文档

如果不确定，则询问用户需要更新哪个文档。
输出文件写入目标目录，结构固定如下：

```markdown
# <目录名> 模块

## 快速索引

| 类名 | 基类/类型 | 简述 |
|---|---|---|
| `ClassName` | BaseClass | 一句话说明 |
```
