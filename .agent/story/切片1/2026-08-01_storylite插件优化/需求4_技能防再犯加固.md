# 需求4：技能防再犯加固

## 需求简介

针对需求3 执行中暴露的"点名后跳过工作流"问题，收紧 story-lite 的激活与门禁规则：点名即激活、定位为强制第一步、铁律事前化；元任务（修改插件自身）不豁免。

## 功能说明

- 策划目标：消除"豁免误判 + 静默跳步"两类失败模式，同时保住轻量性（纯信息问答仍豁免）。
- 技术行为：修改 `plugins/story-lite/skills/story-lite/SKILL.md` 三处（`# 定位`·使用前提、`## 1. 定位与需求整理`、`## 4. 实现与同步维护`铁律）；bump 双 manifest 至 0.1.4；根 README 版本同步；同步 .agent story 文档。纯文档/配置改动，无运行时代码，不涉及网络同步与异常处理。
