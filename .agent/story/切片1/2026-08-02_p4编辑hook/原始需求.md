## 需求背景

工作区文件受 Perforce（p4）管理时为只读属性，直接编辑会失败。需要让 agent 在每次编辑文件前，先尝试对目标文件执行 `p4 edit` 解锁，否则文件无法写入。hook 只在目标项目目录内生效，通过 story-lite 插件提供的配置技能安装到指定目录。

## 需求1：p4 编辑前 hook（项目级）

### 需求描述

1. 双端共用同一脚本：Codex 的 apply_patch、Claude Code 的 Write/Edit/MultiEdit 在 PreToolUse 阶段，对将写入的文件执行 `p4 edit`；
2. best-effort 语义：p4 不存在、目标文件不受 p4 管理、或 `p4 edit` 失败时，仅告警并放行编辑，不阻断；
3. 走默认 changelist（`p4 edit <文件>`，不指定 `-c`）；
4. 项目级部署：配置与脚本都位于目标项目目录内（`.codex/` 与 `.claude/`），只在项目内生效。

### 验收标准

- 目标项目内生成 `.codex/hooks.json`、`.codex/hooks/p4-edit-hook.py`、`.claude/settings.json`（含 PreToolUse hook）；
- hook 脚本从 stdin JSON 解析本次编辑涉及的文件路径（Claude 形态 `tool_input.file_path` / Codex 形态补丁文本 / 环境变量兜底），对不可写的文件尝试 `p4 edit`；
- p4 缺失或 `p4 edit` 失败时仅输出告警，退出码 0，不阻止编辑；
- 配置与脚本可随项目提交、作用域限于项目目录；不写用户级配置（`~/.codex/`、`~/.claude/`）。

## 需求2：配置技能 p4-hook-install（随 story-lite 插件）

### 需求描述

1. 在 story-lite 插件中新增技能 `skills/p4-hook-install/`（含 SKILL.md、安装脚本、hook 脚本与配置模板）；
2. 技能用于把 hook 安装到指定目录：默认安装 Codex + Claude Code 双端，可选 `--cursor`；
3. 幂等：已存在配置时展示差异并覆盖；提供 `--uninstall`，只移除本技能写入的 hook 配置；
4. 插件双 manifest 的 skills 列表同步，版本 0.1.4 → 0.1.5，README 同步。

### 验收标准

- story-lite 插件包含 p4-hook-install 技能，Claude Code / Codex 安装插件后均可发现；
- 技能可对任意指定目录安装/卸载项目级 hook（默认双端，可选 Cursor）；
- 重复安装幂等；卸载只移除本技能写入的内容，保留用户其他配置；
- story-lite 双 manifest 版本 0.1.5，README 同步；本 story 文档同步更新。
