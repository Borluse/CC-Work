## 需求点 1：p4 编辑前 hook

- 状态：已完成
- 关键决策：
  - 项目级部署：配置与脚本进目标项目目录，只在项目内生效；不写用户级配置
  - 双端共用同一脚本：Codex apply_patch / Claude Code Write/Edit/MultiEdit
