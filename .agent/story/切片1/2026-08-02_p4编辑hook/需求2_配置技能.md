# 需求2：配置技能 p4-hook-install

## 需求简介

在 story-lite 插件内新增配置技能：把 p4 编辑 hook 安装/卸载到任意指定项目目录，hook 只在目标项目内生效。

## 功能说明

**策划目标**：把「项目级 p4 hook 安装」做成可复用技能，用户对任意目录说一句即可完成安装，避免手工复制配置、写错路径。

**技术行为**：
- 技能位置：`plugins/story-lite/skills/p4-hook-install/`，随 story-lite 插件分发（Claude Code / Codex 装插件后可发现）；
- 触发：用户说「给 <目录> 装 p4 hook / 配置 p4 编辑解锁 / 安装 p4 hook」等；
- 默认安装 Codex + Claude Code 双端，`--cursor` 可选；
- 幂等：已存在配置时展示差异并覆盖；`--uninstall` 只移除本技能写入的内容。

## 设计细节

### 技能结构（按 skill-creator 规范）

```
skills/p4-hook-install/
├── SKILL.md                 # 触发描述 + 使用流程
├── agents/openai.yaml       # UI 元数据（display_name / short_description / default_prompt）
├── scripts/
│   └── install.py           # 安装/卸载入口（幂等、可逆、校验）
└── assets/
    ├── p4-edit-hook.py      # hook 脚本模板（复制到目标项目 .codex/hooks/）
    ├── hooks.codex.json     # Codex 项目级 hooks 模板
    └── settings.claude.json # Claude 项目级 settings 模板
```

### install.py 行为

```
install.py install <目标目录> [--cursor]   # 安装
install.py uninstall <目标目录> [--cursor] # 卸载
```

- **install**：校验目录存在且可写；写入 `<目标>/.codex/hooks/p4-edit-hook.py`（模板复制，写入安装时绝对路径占位符）；生成/合并 `<目标>/.codex/hooks.json`；生成/合并 `<目标>/.claude/settings.json`（保留其他键）；`--cursor` 时额外生成 `<目标>/.cursor/hooks.json` 并复制脚本；输出安装清单与后续信任步骤；
- **幂等**：重复 install 不产生重复条目（hooks 数组按 matcher+command 去重；Claude settings 保留已有其他键），有差异时先打印 diff 再覆盖；
- **uninstall**：从 `.codex/hooks.json`、`.claude/settings.json`（可选 `.cursor/hooks.json`）移除本技能写入的条目；若文件因此为空/只剩空 hooks 则删除该文件；删除 `.codex/hooks/p4-edit-hook.py`；不动用户其他配置；
- **校验**：脚本内做 JSON 语法校验（写入前 dump + load 回读），保证产物可解析。

### SKILL.md 内容要点

- 触发描述覆盖：「给 <目录> 装 p4 hook」「配置 p4 编辑解锁」「安装/卸载 p4 hook」等；
- 使用流程：定位目标目录 → 运行 `install.py install <目录> [--cursor]` → 展示安装清单 → 说明信任步骤（Codex 项目需 trusted + `/hooks` 审查；Claude Code 首次可能弹审批）→ 验证（可选：用模拟 stdin 测试脚本）；
- 注意：目标项目可能不是 git 仓库，命令用绝对路径；项目移动后重跑安装。

### 插件同步

- `.claude-plugin/plugin.json`：skills 数组追加 `"./skills/p4-hook-install"`；`.codex-plugin/plugin.json` 的 `"skills": "./skills/"` 自动包含，无需改动；
- 双 manifest 版本 0.1.4 → 0.1.5（Codex 附时间戳），README 新增技能说明；
- 不修改其他插件内容。
